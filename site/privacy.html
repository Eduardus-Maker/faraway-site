1 Область действия

Настоящая Политика конфиденциальности описывает, как фан-сайт Arizona Faraway — 26 обращается с данными Пользователя. Документ является неотъемлемой частью Пользовательского соглашения и применяется ко всем страницам Сайта.

Политика составлена с учётом принципа минимизации данных: мы обрабатываем только те сведения, без которых сайт не может работать, и только если это прямо не запрещено.

2 Какие данные мы НЕ собираем

🛡️

Сайт НЕ собирает персональные данные

Мы не используем системы веб-аналитики, рекламные трекеры, cookie-профилирование и не храним IP-адреса посетителей.

В частности, Сайт не собирает и не хранит:

  • IP-адреса и данные геолокации;
  • email-адреса и телефоны, если вы не указали их добровольно в форме;
  • пароли от сторонних сервисов;
  • cookie-файлы аналитики и рекламы;
  • отпечатки браузера и устройства;
  • историю ваших переходов между страницами.

На Сайте отсутствуют:

  • Google Analytics, Яндекс.Метрика и им подобные системы;
  • пиксели социальных сетей (Facebook Pixel, VK Pixel и другие);
  • сторонние рекламные баннеры и партнёрские скрипты.

3 Какие данные всё-таки обрабатываются

Несмотря на минимизацию, часть данных всё же неизбежно участвует в работе Сайта:

Технические данные

  • Запросы к статическим файлам Сайта (HTML, CSS, JS) — обрабатываются хостинг-провайдером в объёме, необходимом для доставки контента.
  • Локальные настройки Пользователя (тема оформления, черновики) — хранятся в браузере и не передаются на сервер.

Данные, которые Пользователь вводит сам

  • Текст жалобы, заявки или предложки — передаётся в редакцию по каналу, инициированному самим Пользователем.
  • Telegram-ID / username и имя профиля — только при добровольной авторизации на служебной странице.
  • GitHub Personal Access Token — только при добровольном использовании панели управления.
⚠️

Важно

Мы никогда не запрашиваем пароли, коды из SMS, данные банковских карт и любую платёжную информацию. Если кто-то от имени Сайта требует такие данные — это мошенничество.

4 Локальное хранилище браузера

Сайт использует localStorage — встроенное хранилище браузера, доступное только на вашем устройстве. Оно не отправляется на сервер и не доступно другим сайтам.

В localStorage могут сохраняться:

  • выбранная тема оформления (ключ azfw26_theme);
  • признак текущей сессии администратора, если вы авторизовались (ключ azfw26_admin_session);
  • черновики записей в панели управления (ключ azfw26_draft);
  • ранее введённые данные о пользователе при авторизации через Telegram.

Вы можете в любой момент очистить localStorage средствами браузера (Настройки → Данные сайтов) или кнопкой «Выйти» в панели управления.

5 Авторизация через Telegram

На служебной странице admin.html доступен вход через Telegram. Авторизация может проходить в двух форматах:

  • через Telegram WebApp (если сайт открыт внутри Telegram);
  • через официальный Telegram Login Widget.

Telegram передаёт нам минимальный набор данных:

  • числовой ID;
  • username;
  • имя и (опционально) фамилию;
  • ссылку на аватар (если открыт доступ).

Эти данные сохраняются только в localStorage вашего браузера. Мы не пересылаем их третьим лицам и не храним на своих серверах. Выход из панели управления удаляет сохранённые данные.

Используя вход через Telegram, вы также принимаете правила самого Telegram — они регулируются отдельными документами Telegram.

6 Авторизация через GitHub

Для работы панели управления поддерживается вход через GitHub Personal Access Token. Токен позволяет панели отправлять коммиты в репозиторий с материалами Сайта.

Как мы обращаемся с токеном:

  • токен сохраняется только в localStorage вашего браузера;
  • токен отправляется исключительно на api.github.com;
  • мы не имеем доступа к токену и не храним его на своих серверах.

Вы можете отозвать токен в настройках GitHub в любой момент — после этого панель перестанет отправлять коммиты. Выход из панели удаляет токен из браузера.

7 Формы Сайта (жалобы, заявки, предложка)

Через формы Сайта вы можете добровольно передать редакции:

  • текст жалобы на игрока;
  • заявку на собеседование (в том числе во фракции);
  • предложение по улучшению сервера;
  • иные сведения, которые вы решили сообщить.

Мы рекомендуем не передавать через формы:

  • пароли и коды из SMS;
  • данные банковских карт и платёжные реквизиты;
  • сканы документов, удостоверяющих личность;
  • любую информацию, которая может быть использована против вас.

Обработка переданных данных ограничена рассмотрением вашего обращения редакцией Сайта. Мы не публикуем и не перепродаём такие данные.

8 Cookies и сторонние сервисы

Сайт не использует собственные cookie-файлы для аналитики, рекламы и трекинга.

Отдельные сторонние сервисы, которые вы можете открыть по ссылкам с Сайта, могут использовать свои cookies. Это регулируется их собственными правилами:

  • Telegram — telegram.org/privacy;
  • GitHub — docs.github.com/site-policy/privacy-policies;
  • Форум и сервисы проекта Arizona RP — на их собственных страницах.

Мы не контролируем cookies третьих лиц и рекомендуем ознакомиться с политикой каждого ресурса, который вы посещаете по ссылке с нашего Сайта.

9 Права Пользователя

Даже при минимальной обработке данных вы сохраняете полный контроль над информацией, которая касается вас лично:

  • Право на доступ. Вы можете запросить у редакции, какие сведения о вас были получены через формы или авторизацию.
  • Право на удаление. Вы можете потребовать удалить ранее переданные сведения.
  • Право на отзыв согласия. Вы можете в любой момент выйти из панели управления и очистить localStorage браузера.
  • Право на возражение. Вы можете запретить дальнейшую обработку ваших обращений, если для этого нет законных оснований.

Для реализации прав свяжитесь с редакцией через официальный Telegram-канал.

11 Безопасность

Мы принимаем разумные меры для защиты Сайта:

  • используем HTTPS для доставки страниц;
  • не запрашиваем и не храним пароли;
  • минимизируем объём обрабатываемых данных;
  • авторизацию в панели управления ограничиваем списком допущенных лиц.

Вместе с тем ни один сайт не может гарантировать абсолютную безопасность. Пожалуйста, соблюдайте базовые правила: не вводите свои пароли на сторонних ресурсах, проверяйте адрес Сайта и не передавайте конфиденциальную информацию по сомнительным каналам.
